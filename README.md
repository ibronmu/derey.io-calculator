# derey.io-calculator
cientific Calculator Web Application
Calculator Screenshot

A feature-rich scientific calculator built with HTML, CSS, and JavaScript that works in any modern web browser.

Features
Core Operations
Basic Arithmetic: Addition (+), Subtraction (-), Multiplication (×), Division (÷)

Decimal Support: Floating point calculations

Parentheses: Support for complex expressions

Clear Function: Reset calculator with AC button

Backspace: Remove last entered digit

Advanced Functions
Square Roots: (√) function

Exponents: (x^y) power function

Trigonometric: sin() and cos() functions

History: Toggleable calculation history panel

User Experience
Responsive Design: Works on desktop and mobile devices

Keyboard Support: Type calculations directly

Visual Feedback: Button animations and hover effects

Error Handling: Clear error messages

How to Use
Basic Calculation
Click number buttons to enter your first number

Select an operator (+, -, ×, ÷)

Enter your second number

Press "=" to see the result

Advanced Usage
Use parentheses for complex expressions: (2+3)*4

Click "√" for square roots (e.g., "√9" = 3)

Use "x^y" for exponents (e.g., "2 x^y 3" = 8)

Trigonometric functions work in radians

Keyboard Shortcuts
Numbers: 0-9 keys

Operators: +, -, *, / keys

Enter: Calculate (=)

Escape: Clear (AC)

Backspace: Delete last character

Parentheses: ( and ) keys

Installation
No installation required! Simply:

Download the calculator.html file

Open it in any modern web browser

Start calculating

Or use it directly by hosting it on any web server.

Customization
To modify the calculator:

Change Colors: Edit the CSS variables in the :root selector

Add Functions:

Add new buttons in the HTML

Create corresponding JavaScript functions

Adjust Layout:

Modify the grid layout in .calculator-grid

Change padding/sizing in the button styles
